# Changelog

All notable changes to the BenchCAD dataset and harness. The dataset is versioned
with HuggingFace revision tags; each release here corresponds to a tag on
`BenchCAD/BenchCAD`.

## [Unreleased]
- Contribution infrastructure: `CONTRIBUTING.md`, `tools/regrade.py` (re-grade
  submitted predictions), errata process.

## [v1.0] — 2026-06
- Initial release: `code_gen` (17,900 samples / 106 part families),
  `QA` (2,400 numeric questions / 200 parts), `edit-bench` (held-out edit set).
